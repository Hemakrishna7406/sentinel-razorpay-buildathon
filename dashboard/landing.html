02 — Intent

Every intent passes through the pipeline

Each action an AI agent requests — checkout, payout, refund — is intercepted by Sentinel before execution. The intent's properties (amount, recipient, timing, velocity) are extracted as features and compared against the agent's behavioral baseline in real time.

03 — Behavioral Drift

Detecting when the rhythm breaks

Sentinel continuously compares the agent's current window against its established baseline. A compromised agent's behavior drifts: amounts spike, velocity increases, new recipients appear, operating hours shift. The behavioral drift score captures the compound deviation across all dimensions simultaneously.

04 — Decision

Measured on held-out data, not vibes

Sentinel's XGBoost detector is evaluated on a temporally-split held-out test set that the model never saw during training. The threshold is frozen on a validation set, then applied to the test set unchanged. An ablation study confirms that behavioral features outperform transaction-only and rules-only baselines.

05 — Containment

Zero-trust execution boundary

Detection alone doesn't prevent losses. Sentinel issues a cryptographically signed Capability Token that locks the exact amount, recipient, currency, and action. The execution adapter independently verifies 10 invariants before allowing any mutation. No valid token, no execution — fail closed, always.
